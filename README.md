# Teo's Research Notebook

Personal essays and experiments on AI, machine learning, computer science,
statistics, mathematics, and adjacent psychology.

The site is built with Jekyll on the [minima](https://github.com/jekyll/minima)
theme and published under the `/blogs` path on GitHub Pages.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

Posts go in `_posts/` as `YYYY-MM-DD-title.markdown`. The generated `_site/`
directory is ignored.
